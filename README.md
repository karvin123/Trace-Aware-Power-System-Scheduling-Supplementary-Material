# Supplementary Material

This repository hosts the supplementary material for the paper:

**Trace-Aware Power System Scheduling with Heterogeneous Power Sources: A Learning-Based Framework**

The supplementary document contains:

- the modified IEEE 14-bus test-system and scheduling parameters;
- neural-network training and MILP reformulation details;
- practical-scale transmission-system parameters; and
- supplementary topology and held-out parity figures.

Files:

- `Supplementary_Material_for_Trace_Aware_Power_System_Scheduling.pdf`: compiled supplementary material.
- `Supplementary_Material_for_Trace_Aware_Power_System_Scheduling.tex`: editable LaTeX source.
- `figure/`: figure files required to compile the supplement.
